# v1.8.6 — Local owner review

Packages the current native monitoring app for installed-version comparison.
Rocinante uses the reviewed warm instrument styling, original owner-supplied
crew emblem and latest separate S6 fan model. The left showcase, temperature
dials, solar navigation and established monitoring positions are retained.
Pella retains its accepted console and latest model. Holotables are passive
rotating stages, and settings use the direct form rather than nested menus.

Full model geometry, embedded textures, shading, existing 4x MSAA and accepted
rotation timing remain unchanged by this packaging pass. The Roci hull finish
and close-up image quality remain subject to owner review; no anti-aliasing or
resolution repair is claimed. Fleet Studio remains a separate desktop viewer.

The source candidate passed the LIVE Roci runtime check before packaging.
Installer build and published-file checks are separate from installation and
the owner's installed visual comparison. This is a local installer, with no
public release, upload or installation performed by the build script.
