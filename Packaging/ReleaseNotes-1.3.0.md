Adds four **Expanse-inspired ship-console themes**: Rocinante, MCRN Tactical, UNN Command and Belt Salvage. These replace the AORUS side artwork with responsive modular CPU/GPU consoles, compact memory/network sections, new typography, original vector symbols and different temperature-dial frames. The original eleven themes remain available.

Removes decorative background grids, scanlines, hatch patterns and graph grids across the entire collection. Backgrounds now use clean surfaces and restrained colour washes.

The ship consoles use the same collected values, source labels, units, peaks and unavailable states as the AORUS presentation. Theme switching keeps readings, maxima, display and polling settings. No fictional system states or simulated telemetry are added. The original AORUS artwork timer stops while a ship theme is selected; no new animation timer or downloaded artwork/font pack is added.

Visual reference: [Rhys Yorke's Rocinante UI portfolio](https://rhys.artstation.com/projects/q9Am1L). These are independent fan interpretations, not official show interfaces; no show screenshots or official faction logos are bundled.

Validation includes sensor/display/theme checks, structural ship-layout checks across screen sizes and layout modes, and visible saved-reading walkthroughs of the four ship consoles with a return to AORUS Dark. Rendering, text bindings, unchanged sensor values/maxima and settings bounds are checked separately from installed/live validation. Programmatic button-handler walkthroughs do not establish native mouse behavior on every display or DPI combination.

Requires the shared Microsoft .NET 10 Desktop Runtime (Windows x64, stable 10.0.x), existing PawnIO 2.2+ for CPU/motherboard readings, and the installed NVIDIA driver for GPU readings. Independent FAN MADE project; show and AORUS names/trademarks belong to their owners.
