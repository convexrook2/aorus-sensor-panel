# Arboghast /011 pass08 source

Original X890 reconstruction after Chris Danelon's production turntable,
reviewed from the owner's OBS recording. The owner confirmed pass08 in Fleet
Studio and requested Sensor inclusion on October 22, 2026. These are exact
copies of the editable Blender scene and its full GLB export; source hashes
and limits are recorded in provenance.json. No production mesh was acquired.

The Sensor uses a lossless copy at Assets/FleetViewer/models/Arboghast.glb.gz.
The prepared portrait is bound to the same decoded GLB hash. The old
Assets/Models/Source/Fleet/Arboghast.glb and Arboghast.ship remain preserved
legacy assets; the current showcase, holotable and portrait use pass08.

Exact dimensions, hidden fittings and light photometry remain authored fits.
Original studies and video-frame research stay in their separate source and
output folders. Standalone Fleet Studio installation is a separate scope.
