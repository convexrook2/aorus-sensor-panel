# Asset collection

`AORUS/` contains the source skin assets used by the standalone panel. The
application embeds selected fonts, images and animation frames. Rainmeter
configuration files serve as layout references; copied plugins and executables
are not loaded or executed by the panel.

`Ships/` contains ship artwork with source records in
[sources.json](Ships/sources.json). `Models/` contains the compact scene archives
for the included 3D ships, with artist credits, source links, licences and
conversion details in [ATTRIBUTION.txt](Models/ATTRIBUTION.txt).

Razorback currently uses flat artwork. The referenced red-and-white 3D model
has not been bundled; an authorised download and redistribution terms are
needed before it can be included.

Artwork, fonts, models and trademarks remain their respective owners'
property. Keep all source records and attribution notices with redistributed
assets. This is an independent fan project without an endorsement from the
referenced brands or artists.
