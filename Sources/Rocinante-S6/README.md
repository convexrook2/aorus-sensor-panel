# Editable finished Rocinante

`Rocinante-S6.blend` is the packed editable source for the owner-finished
20 October 2026 revision. It is intentionally outside the runtime asset roots.
See [the finished baseline](../../docs/ROCINANTE-S6-FINISHED.md) for exact exported
model identity, scope and preservation requirements.

Original geometry: Martin Taichl / Martin,
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/),
[source](https://www.printables.com/model/136343-rocinante-from-the-expanse).
Modified PBR finish, paired relief colours, existing lettering colours,
bluish-grey optical armour and emissive fixture materials are retained.
The drive exhaust is a separate runtime effect in `FleetStudio/ship-effects.js`.
No TV images or video frames are bundled as model textures.
