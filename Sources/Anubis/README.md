# Anubis source assembly

Martin Taichl / Martin / taichl's [Amun-Ra kit](https://www.printables.com/model/123750-amun-ra-class-stealth-frigate-from-the-expanse), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). All 26 original STL files and their acquisition hashes are retained in this folder. The creator describes this fan kit as bulkier than the studio ship; it is not official production geometry.

The owner accepted the assembled hull, fittings, charcoal finish, drive lights and exhaust on 2026-10-20, then authorized completing the red cluster, the blue bow light and adopting Anubis into the main fleet. `identity.json` pins the adopted GLB. `Anubis-accepted-before-red.glb` preserves the accepted base. All source coordinates, triangle winding, normals, UVs, fitting transforms and the procedural texture remain exact. Approved material routing selects 516 existing recessed cap faces for red and 80 inward bow-lining faces for blue-cyan; the rejected exterior strip is charcoal.

The exterior amun9 blue strip and the later upper-only flat glow were rejected by the owner. The supplied production close-up and owner correction require emitted light around the full existing interior. All 80 inward amun10 lining faces retain their gaps, with uneven bright patches and confined spill above/below/on both sides. After viewing that revision, the owner requested light on the actual background as well and rejected the head-on floating-dot appearance. The accepted display correction removes those sprites, adds two measured concealed rear fills for the existing wall and port surround, and uses the shared fleet emission-only glow. The owner accepted it on 2026-10-20: “Accepted. A bit bright, but accepted.” Brightness is preserved. The cyan markup indicates placement, not a new physical tube. Exact accepted model 067fc6b196b64a2fe90e2df63a87ad76d15cea22433f6c05cece38ab3420c43f and lighting hashes are pinned in [owner-acceptance.json](owner-acceptance.json). Its material-recipe pointer was relocated to the identical retained `review-finish.py`; no accepted hash or lighting value changed. **Anubis main fleet** completed the guarded import on 2026-10-20; source, Studio, native bundle and Debug desktop copy decode to the same GLB. The local rollback is artifacts/anubis-main-fleet-20261020-234357; 52 other existing model hashes were preserved. Exact lens segmentation and function remain unresolved.

The red material follows two localized cheek groups beneath the raised spine, between the pod-bearing banks, seen in [Chris Danelon's production turntable](https://www.youtube.com/watch?v=vefkFrWLuNI). The footage merges individual lenses into glow; the kit's three existing caps per cheek were retained. Top-row ports, the opposite spine and drive-bracket caps were not made red. No hull surface or fitting was added, removed, mirrored, rounded or stretched. Cyan drive emission remains on 34 existing rim-cap triangles and 154 throat triangles. The independent blue-white plume uses the existing source outlet; its display length is an interpretation.

`review-finish.py` holds material masks and rigid fitting registrations. `prepare-review.py` can reproduce the separate inspection bundle from these retained inputs; it locates this checkout through `X890.code-workspace`. Run `python Sources/Anubis/prepare-review.py` explicitly to generate the ignored `DesktopReview/` and `Anubis-source-assembly.glb` alongside the recipe; it also refreshes the assembly report. Missing local research captures are skipped. The final design sheet in [Early Development of the Anubis at 4:35](https://www.youtube.com/watch?v=F_dbeZ8pWtY&t=275s) distinguishes final asymmetry from earlier concept variants. Production and paid Sketchfab references were inspected only; no paid model data or reference imagery is redistributed here.

The main Fleet Studio and native bundle use the same lossless model. `tools/Check-AnubisAdoption.py` checks their parity, retained acceptance hashes, source preservation, emissive face counts, drive registration and the frozen Rocinante asset. Its red-face comparison uses the retained `Anubis-red-only.glb.gz`, rather than requiring an intermediate hosted model. Run **Check Anubis main fleet (no install)** in VS Code. These canonical checks need no generated `output/` or local research files.

To inspect an explicitly prepared candidate, use `python tools/Check-AnubisAdoption.py --candidate --review-root <prepared-directory>`. Omitting the directory selects this retained source folder after running its recipe. The bow-control check accepts `node tools/Check-AnubisBowEffects.mjs --model <candidate.glb>` and otherwise checks retained `Anubis.glb`. `tools/Adopt-Anubis.py --correct-bow` defaults to the retained accepted source; an already adopted revision is verified without rewriting assets. An explicit `--review-root <prepared-directory>` selects a generated candidate for the guarded import. Installation, CI and publishing remain separate actions.
