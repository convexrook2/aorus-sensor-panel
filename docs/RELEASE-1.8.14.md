# SensorPanel 1.8.14 candidate

Lennon accepted Pella v27 and Scirocco paint02 and requested their integration
into Fleet Studio and SensorPanel. After the completed integration report
identified release and installation as the next step, he asked to continue.
This candidate contains those exact ships and the previously requested,
locally validated AORUS memory/FPS correction. Release execution and installed
verification are recorded separately from preparation.

Included: accepted Pella/Scirocco source exports and editable Blender files,
catalogues, outlet registrations, matching native portraits, attribution,
renderer routing, adoption checks and the AORUS memory/discovery/FPS lifecycle
changes documented in `AORUS-MEMORY.md`. Canonical GLBs are versioned with
lossless gzip; their decompressed hashes equal the accepted files. Existing
uncompressed local sources remain intact.

Excluded: reference research, rejected/procedural ship studies, downloads,
heap dumps, preview servers, and unrelated AGENTS/reference documentation
edits. Other accepted ships and their source geometry remain unchanged.

The October 24 pre-release native checks verified both ships in the protected
SensorPanel showcase and holotable. The separate Fleet Studio desktop was
already refreshed and verified. The memory evidence is the completed LIVE
LMU run documented in `AORUS-MEMORY.md`; it does not establish an unsampled
absolute ceiling or a new installed-app result.

Candidate identity, source checks, exact-source Jenkins build, installer and
publication receipts are retained under `artifacts/release-1.8.14`. Until those
receipts say otherwise, source preparation does not mean publication or
installation. Installation preserves the owner's preferences and startup
choices and must use the exact verified release package.

Shared runtime preservation: the 1.8.14 Anubis runtime amendment records only
the current shared viewer registration hash after the Pella/Scirocco additions.
The original acceptance and historical runtime receipts remain intact. Its
source geometry, materials, lighting and shared effect shaders are unchanged;
the source adoption gate continues to verify those identities.
